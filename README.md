# Tobermory Family Trip

Shortlist board for a family weekend near Tobermory and the Grotto, Fri Jul 9 – Sun Jul 11, 2027.

Static page: open `index.html`. Deep links look like `index.html#n=3` — they open that place's card with its details expanded. Each card also has a Copy link button.

Prices in CAD, checked Nov 12, 2026. Photos from the listings themselves; they are embedded in the `photos-data-*.js` files as data URIs (the JPEG originals live in `images/` locally) so the page has no external image dependencies.
